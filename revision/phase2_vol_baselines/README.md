# Phase 2 — Volatility-Specific Baselines

## 背景與動機

Phase 1 確認 Linear vanilla 能打贏 Persistence（15/16），paper 基礎穩固。
Phase 2 進一步補充四個波動率預測領域的標準統計基線，回應學長建議：

> 「未納入 HAR-RV、EWMA、GARCH 等波動率預測核心基線，難免遭受質疑。」

## 四個基線說明

### 1. EWMA（λ=0.94，RiskMetrics）
**公式：**
```
σ²_t = λ · σ²_{t-1} + (1-λ) · r²_t
```
- 指數加權移動平均，對近期報酬率賦予更高權重
- λ=0.94 為 J.P. Morgan RiskMetrics 標準參數
- 多步預測採「flat forecast」（條件方差為隨機遊走，h 步預測 = 當期值）
- 轉換：`σ_ann = sqrt(ewma_var * 252) * 100`

### 2. HAR-RV（Corsi, 2009）
**公式：**
```
σ_{t+h} = β₀ + β_d · σ_t + β_w · σ_t^(w) + β_m · σ_t^(m) + ε
```
- 三個尺度的已實現波動率：日（σ_t）、週（5日均值）、月（22日均值）
- 使用 OLS 迴歸，對 h=1,2,3 各訓練一個獨立模型（direct multi-step）
- 波動率領域的 gold standard baseline（Corsi, 2009）
- 僅 fit 訓練集，測試集直接預測

### 3. GARCH(1,1)
**公式：**
```
σ²_t = ω + α · ε²_{t-1} + β · σ²_{t-1}
```
- 建模條件異方差，捕捉波動率叢聚效應
- 使用 `arch` 套件，fit 訓練集的 log_return（×100）
- h 步預測使用解析遞迴公式：
  `σ²_{t+h|t} = σ²_∞ + (α+β)^h · (σ²_t - σ²_∞)`
- 轉換：`σ_ann = sqrt(σ²_{t+h} / 10000 * 252) * 100`

### 4. GJR-GARCH（Glosten, Jagannathan & Runkle, 1993）
**公式：**
```
σ²_t = ω + α · ε²_{t-1} + γ · ε²_{t-1} · 𝟙[ε_{t-1}<0] + β · σ²_{t-1}
```
- 非對稱 GARCH，負向衝擊（γ > 0）對波動率的影響大於正向衝擊
- 捕捉金融資產常見的「槓桿效應」
- h 步預測使用半方差修正：`persistence = α + 0.5γ + β`

## 評估設定

| 項目 | 設定 |
|------|------|
| 資料集 | 16 個（TWD FX ×7、International FX ×3、Taiwan Stocks ×6） |
| 分割比例 | 70 / 10 / 20（train / val / test） |
| 預測目標 | 7日滾動年化波動率（%），horizon = 3 天 |
| 指標 | RMSE / MAE / MDA（原始尺度，與主實驗一致） |
| 比較對象 | Persistence（Phase 1）、Linear vanilla（5-seed 均值）、TSB（5-seed 均值） |

### 時間對齊（重要）

所有基線的「當前時刻 t」定義與 DL 模型完全一致：

```
DL 模型輸入窗口: features[split_2+i-30 : split_2+i]
DL 模型最後已知: features[split_2+i-1]  ← last known = split_2+i-1
DL 模型預測目標: features[split_2+i : split_2+i+3]
```

統計基線同樣使用 `t = split_2+i-1` 作為最後已知時刻，預測 h=1,2,3 步。
**任何使用 `split_2+i`（即第一個 target）作為特徵的實作均為 data leakage，本腳本已修正此問題。**

> 開發過程中曾發現一個 off-by-one bug：HAR-RV 誤用 `t_idx = split_2+i`（target 的第一個值）作為特徵。
> 修正前 TSB vs HAR-RV：0/16；修正後：15/16。

## 結論

### 正面：TSB 在所有統計基線上全面勝出（15–16/16）

- **vs EWMA / GARCH / GJR-GARCH**：16/16，改善幅度 37–44%，差距顯著
- **vs HAR-RV**（最強基線）：15/16，平均改善 **+13.97%**
  - HAR-RV 是領域 gold standard，能在此基線上勝出是論文最有力的結果
- 唯一例外 **0050_TW** 仍為已知資料品質問題（見 Phase 1 README）

### HAR-RV 是論文最重要的比較對象

GARCH / EWMA 表現遠差於 TSB，差距太大反而顯得基線太弱。
HAR-RV 差距適中（+13.97%），且在學術上被廣泛認可，是論文結論的最佳支撐點。

**建議將主要結論從「比 Linear 好 15%」更新為「比 HAR-RV（gold standard）好 ~14%」**，
同時保留「比 Linear 好 15%」作為 DL 框架內的比較。

### GARCH 系列表現差的原因

GARCH 建模條件異方差（instantaneous variance），而本研究的預測目標是 7 日滾動波動率（rolling window）。
兩者在定義上存在根本差異：GARCH 的 h 步預測是「均值回歸的條件方差」，
而目標 σ_{t+h} 由 r_{t+h-6:t+h} 計算，包含大量歷史資訊，遠比 GARCH 假設的 instantaneous variance 平滑。
此差異應在論文 Experiment section 說明。
